# React design and prototype — retained for future work

The current JachAI UI is the same-origin HTML/CSS/JavaScript application documented in [FRONTEND.md](../../../FRONTEND.md). React was explored as a possible later migration, but its pilot is not the production dashboard and should not be merged wholesale over the current UI.

Keep the original [handoff](HANDOFF_REACT_UI.md), [detailed delivery/design record](REACT_DASHBOARD_DELIVERY.md), and [visual prototype](../../prototypes/directions.html) together as research. Their historical port, database, branch, and worktree instructions are evidence of that experiment, not instructions to run today's app. If React work resumes, compare the pilot against current `main`, choose one screen at a time, and preserve existing auth/role boundaries.
