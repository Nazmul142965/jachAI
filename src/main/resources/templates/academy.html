A class, from start to finish

Seven steps, from an empty workspace to a certificate.

  1. Set up the workspace

    An admin invites instructors and learners by email. Each person only sees what their role allows.

    Staff

  2. Build a question bank

    Write multiple-choice or short-answer questions. A draft, even one made by AI, must be approved by a person before anyone can use it.

    Staff

  3. Publish a test

    Publishing saves a fixed copy with its time limit and pass mark. Later edits never change old results.

    Staff

  4. Add learners to a batch

    A batch has start and end dates. Every learner in it gets the test, and people who join later get it too.

    Staff

  5. Learners take the test

    The server keeps the time. Answers save as you go, and you can come back to a test you have not finished.

    Learner

  6. Grade, release and give feedback

    Staff mark the written answers, then show results at once or later. Instructors can add private feedback for each learner.

    Staff

  7. Give certificates

    A learner who passes gets one certificate. Anyone can check its code online, and the page never shows the learner's private details.

    Server

What your class gets

Three promises that do not depend on the browser.

Fair scores

The server scores multiple-choice answers with fixed rules. AI can explain a result, but it can never change one.

Honest status

Answers waiting to be graded and results not yet released are shown as they are. Nothing looks finished before it is.

Certificates people can trust

Every certificate has a code. A public page says whether it is valid or cancelled, and since when.
