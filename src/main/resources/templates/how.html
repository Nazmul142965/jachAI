How it works

From a question to a certificate you can verify.

JachAI runs the whole life of a test in one place. People write and review the questions. The server keeps the time, the scores and the records, so a result still makes sense later.

The journey of one test

Seven steps. The same path for a class and for a hiring round.

  1. Write questions

    Staff write the questions. AI can draft some, but a person must approve each one.

    Staff

  2. Publish a version

    The test is saved as a fixed version. A later edit makes a new version, so old results never change.

    Staff

  3. Invite people

    Learners or candidates get the test with a start date, an end date and a number of tries.

    Staff

  4. Take the test

    The server starts the timer and keeps the deadline. The clock on screen is only a guide.

    Server

  5. Submit answers

    Each answer is saved as you go. Pressing submit twice by accident changes nothing.

    Learner

  6. Score and review

    Multiple-choice answers are scored by fixed rules. Written answers wait for a person to grade them.

    Server

  7. Release and verify

    Staff release the result. A learner who passes gets a certificate that anyone can check online.

    Staff

Who does what

Three kinds of people, each with a clear job.

Organization admins

Set up the workspace, add people, choose the plan and decide how results are released.

Instructors and recruiters

Build questions, publish tests, review answers and release results.

Learners and candidates

Take the test, see the released result, and get a certificate if they pass.

A result travels like this:

  • Admin sets up
  • Staff build and assign
  • Learner takes the test
  • Server scores it
  • Staff release it
  • Learner sees the result

The server is the referee

Three rules that nobody can bend from a browser.

It keeps the time

The deadline lives on the server, so a changed clock or a slow connection cannot cheat anyone or hurt anyone.

It freezes the test

A published version never changes, so every learner is judged by exactly the same questions.

It owns the score

Scores come from fixed rules. AI can explain a result, but it can never change one.

AI helps, people decide

AI is a helper inside the process. It is never the examiner.

AI helps with

  • Drafting questions for a person to review.
  • Explaining a result to the learner after it is released.
  • Answering study questions in the AI Tutor, outside exams.

AI never

  • Changes an official score.
  • Publishes a question that nobody reviewed.
  • Answers while an exam is running.

JachAI can note things like leaving the tab or pasting text during a hiring test. These are hints for a person to read. They are not proof, and nothing blocks the test automatically.

Safe by design

The same rules protect every organization.

Every organization is separate

Each record belongs to one organization, and every request is checked against it.

Roles are checked on the server

Hiding a button is never the protection. The server checks your role every single time.

Important changes are logged

Who changed a role, published a test or issued a certificate is recorded with the time.
