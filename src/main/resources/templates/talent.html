A hiring round, from start to finish

Seven steps, from an open role to a recorded decision.

  1. Set up the workspace

    An admin adds the recruiters. Candidates get a narrow role that only reaches their own tests and results.

    Staff

  2. Publish the test

    Questions are approved by a person first. Then the test is saved as a fixed version with its time limit and pass mark.

    Staff

  3. Open a campaign

    A campaign keeps the exact version it started with, so a later edit cannot change what candidates were measured on.

    Staff

  4. Invite candidates

    Pick someone who already has an account, or send an email invitation. The link stops working after 14 days, or when the test closes if that is sooner.

    Staff

  5. Candidates take the same test

    The server sets the deadline and saves each answer. The rules are the same for everybody.

    Candidate

  6. Compare and decide

    See each candidate's latest result side by side. Leave a note, then choose hold, shortlist or reject. Every decision keeps who made it, the note and the time.

    Staff

  7. Release results on purpose

    If you choose manual release, candidates see nothing until you release it. They never see the answer key.

    Server

What your team gets

Three things that make the comparison fair.

Results you can compare

One fixed test, one timer and a score for each topic, so you compare like with like.

Decisions with a history

Notes and decisions are added to a history. Later, anyone on the team can see who decided what, and when.

Respect for candidates

A candidate sees only their own test and result, never another candidate's data.

Integrity signals, used honestly

Hints for a person to read. Never a verdict.

What JachAI can note

  • Leaving the tab, leaving full screen, and copying or pasting.
  • How long each answer took to save.
  • It does not store IP addresses, clipboard text or keystrokes, and the notes are deleted after 90 days.

What it never does

  • Decide that someone cheated.
  • Block or fail a candidate by itself.
  • Treat the signals as proof. A candidate can hide or fake them.
